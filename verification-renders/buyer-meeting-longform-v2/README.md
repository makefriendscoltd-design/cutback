# 강의용 문장 자막 v2

사용자 피드백(2026-09-14): 제공한 참고 이미지처럼 자막을 크게, 영상 하단 안쪽에 배치한다. 강의이므로 한 문장을 한 번에 보여주고, 문장이 길어 한 줄을 넘을 때만 의미 단위로 나눈다. 이전 35자/4.2초 기준은 폐기한다.

정본: `sentence-groups.json`(완결 문장·원본 시간), `caption-style.json`(표현 규칙), `build_captions.py`(줄 너비에 따른 의미 분할), `assemble.py`(합성). 기존 원문 교정과 컷/음성/모션은 v1 그대로다. `assets`, `renders-graphics`, `cut-base.mp4`는 v1 로컬 의존성이다.

107개 문장을 바탕으로 실제 글꼴 폭을 측정하여 184개 표시 구간을 만들었다. 너비가 맞는 문장은 시간이나 글자 수 때문에 추가 분할하지 않는다. 길이 제한으로만 분할하며 짧은 서술어 꼬리만 남지 않도록 균형과 의미 경계를 함께 고려한다. 출력은 모두 한 줄이다.

Pretendard SemiBold, 흰색, 검정 블록 68%. ASS 글자 크기 50(종전 30), 하단 마진 132(종전 22). libass의 글꼴 높이 환산을 반영한 CSS/Pillow 근사치는 41px이며, 실제 출력 프레임에서 크기·폭·위치를 확인했다. 이번 시각 레퍼런스가 이전의 캡컷 크기 5 추정값보다 우선한다. 자막은 강사 얼굴과 슬라이드 저작권 문구를 가리지 않는 위치에 둔다.

재생성: `python3 build_captions.py`, `python3 assemble.py`, NumPy/Pillow가 있는 Python으로 `verify_delivery.py`. 완성 MP4는 Downloads의 `바이어_온라인_오프라인_미팅_롱폼_편집_v2_문장자막.mp4`다. 12분 14초, 1080p25; 영상 내용과 음성은 v1과 동일하다.
