# Photo source and license evidence

Google search was attempted in Orca's embedded browser using the `site:pexels.com/photo` queries recorded in `assets.json`. Google returned its automated-traffic verification page (`https://www.google.com/sorry/…`) on 2026-09-12, showing the original query URL. The same queries were routed through agent-reach/Exa to discover the Pexels result pages. Each final asset's Pexels page and download URL were then checked directly through the Jina reader (`https://r.jina.ai/<source_page_url>`).

Pexels license source: https://www.pexels.com/license/

License evidence text observed on 2026-09-12:

- "All photos and videos on Pexels are free to use."
- "Attribution is not required."
- "You can modify the photos and videos from Pexels."
- Online uses explicitly listed include websites, e-commerce shops, newsletters, e-books, presentations, blogs, and sold templates.
- Restrictions include offensive depiction of identifiable people, selling unaltered copies, implying endorsement by people or brands, and redistribution on stock-photo or wallpaper platforms.

This set was visually screened for the planned small pop-up treatment. It contains no clearly identifiable faces in the intended crops and no visible third-party brand marks. Device screens show generic work or code interfaces and should stay small enough that interface details are not presented as endorsements.
