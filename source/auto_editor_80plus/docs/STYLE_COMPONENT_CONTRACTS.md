# Style Component Contracts

모든 컴포넌트는 1080x1920 기준 design token을 입력받고, scene JSON만으로 deterministic하게 렌더되어야 한다.

## Oren
- OrenSerifChapterTitle: 상단 대형 세리프, 2~3줄, 일반 자막과 계층 분리
- OrenUpperUiOverlay: 화자 얼굴을 피한 상단/후면 UI 증거
- OrenReferenceBurst: 여러 레퍼런스 이미지를 짧은 hard-cut burst
- OrenEvidenceFullscreen: 결과/증거 구간 풀스크린

## Jack
- JackBigKeyword: 감정/핵심 주장 순간 대형 산세리프
- JackStoryMontage: 0.45~1.2초 B-roll 연타
- JackPatternInterrupt: 흑백/배경제거/프레임 변화 등 제한적 인터럽트
- JackEvidenceOverlay: 구체 사례 화면 + 화자 복귀

## Lazy Owen
- LazyToolCard: 툴 이름 + 실제 UI 카드
- LazyDarkNeonPanel: 다크/네온 기술 UI
- LazyBenefitPunch: 무료/무제한/숫자/성과 대형 강조
- LazyStackSequence: 툴 여러 개를 동일 레이아웃으로 0.8~1.8초 교체
- LazyProfileCTA: 토킹헤드 + 프로필 카드
