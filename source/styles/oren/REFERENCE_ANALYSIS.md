# Reference analysis summary

Analyzed 5 vertical reels from the same creator.

## Technical
All references are 720x1280 vertical. Durations range ~48s to ~130s. Frame rates are ~24 or 30 fps.

## Measured major scene-change cadence
Scene-change detection was run at a consistent threshold.
- Ref 1 (94s): ~1.45s average per major visual change
- Ref 2 (130s): ~1.67s
- Ref 3 (101s): ~1.72s
- Ref 4 (98s): ~1.51s
- Tutorial ref (48s): ~2.52s

This supports two recurring modes rather than one uniform pacing profile.

## Recurring grammar
- Talking head is the narrative anchor, not the only visual.
- Essay/story reels use heavy full-screen B-roll, photographs, screenshots, book covers, products, places, and aspirational/lifestyle visuals.
- Tutorial uses speaker + UI overlays and reserves fullscreen for proof/demo.
- Large white editorial serif phrases appear at the hook and thesis/pivot moments.
- Dialogue subtitles are much smaller and visually quiet.
- Hard cuts dominate.
- External visuals are chosen semantically: concrete noun -> concrete visual; proof -> evidence screenshot; number -> oversized number; before/after -> visual comparison.
- Long static passages are rare.

## Important limitation
A raw talking-head video alone is not enough to recreate the reference grammar unless the pipeline can also obtain relevant B-roll/evidence assets. Without asset retrieval, the system can automate trims, captions, typography, zoom/crop, and simple overlays, but will not match the reference style closely.
