# JACKLAYDENN REELS EDITING SKILL v1

## 0. 목적
이 Skill은 9:16 토킹헤드 원본을 jacklaydenn 레퍼런스 3편의 공통 편집 문법으로 변환하기 위한 판단 규칙이다.
핵심 목표는 특정 프레임을 복제하는 것이 아니라 다음의 반복 패턴을 재현하는 것이다.

- 토킹헤드를 시각적 앵커로 유지한다.
- 자막은 문장 전체가 아니라 의미 단위의 짧은 단어/구로 사용한다.
- 핵심어, 숫자, 이름은 일반 자막보다 훨씬 크게 처리한다.
- 증거/사례/인물/장소가 등장하면 실제 이미지·스크린샷·B-roll로 치환한다.
- 설명 강도에 따라 화면 변화 밀도를 3단계로 조절한다.
- 스토리와 감정이 강해질수록 B-roll 밀도가 상승하고, 이후 토킹헤드로 복귀해 리듬을 리셋한다.

## 2. 스타일의 최상위 원칙

### RULE A — Talking head is the anchor
영상의 기본 상태는 인물 토킹헤드다. B-roll과 그래픽을 계속 쌓아도 시청자가 누구의 이야기인지 잃지 않게 한다.

### RULE B — Visualize meaning, not every word
대사를 그대로 화면에 반복하지 않는다. 의미를 시각화할 수 있는 명사, 사람, 장소, 숫자, 결과, 사례가 등장하면 이를 이미지/영상/스크린샷으로 치환한다.

### RULE C — Caption is a rhythm device
자막은 자막 그 자체보다 리듬을 만드는 요소다. 한 번에 긴 문장을 보여주지 않고 1~4단어의 짧은 의미 덩어리를 순차적으로 교체한다.

### RULE D — Escalate visual intensity
중요도가 올라가면 아래 순서로 시각 강도를 높인다.
1. 일반 짧은 자막
2. 대형 키워드/숫자
3. 이미지/스크린샷 오버레이
4. 풀스크린 B-roll
5. 고밀도 B-roll montage
6. 특수 패턴 인터럽트(흑백/반전/배경 제거 등)

### RULE E — Reset after a burst
B-roll 몽타주나 강한 효과가 3~8초 이어졌다면 토킹헤드로 돌아와 시각적 기준점을 리셋한다.

## 3. 강도 모드

### MODE 1 — EXPLAINER
사용 조건:
- 개념 설명
- 리스트/방법론
- 교육형 문장
- 감정 강도가 낮음

편집:
- 토킹헤드 비중 높음
- 2~4초마다 큰 화면 변화 검토
- 일반 자막은 계속 짧게 교체
- 핵심 키워드만 대형 처리
- B-roll은 증명/예시가 필요한 순간에만 1~2개

참고: `Da7zY1vgJX2`의 설명 구간과 유사한 밀도.

### MODE 2 — HYBRID
사용 조건:
- 주장 + 사례
- 교육 + 개인 경험
- 레퍼런스/크리에이터/사례를 여러 개 소개

편집:
- 토킹헤드와 자료 화면을 적극 교차
- 큰 시각 변화가 대략 1.2~2.5초마다 발생하도록 설계
- 2~4개 B-roll을 짧게 묶는 micro-burst 허용
- 증거 자료는 인물 위/뒤 또는 풀스크린으로 사용

참고: `DbVP68dgw0d`와 유사한 밀도.

### MODE 3 — STORY_MONTAGE
사용 조건:
- 개인 경험
- 시간 흐름
- 사건 발생
- 실패/고통/감정 변화
- 여행/도전/회고형 이야기

편집:
- 사건이 시작되면 풀스크린 B-roll 우선
- 강한 구간에서는 약 0.5~1.2초 단위의 연속 컷 허용
- 실제 현장 영상, 휴대폰 영상, 사진, 문서, 위치, 인물 중심
- 감정 피크에서 흑백/고대비/반전 등 단기 효과 사용 가능
- 4~8초 이내 토킹헤드 복귀 지점 검토

참고: `DbicmDVAweu`의 중후반 스토리 구간과 유사한 밀도.

## 4. 장면 유형

### J01 TALKING_HEAD_BASE
기본 화면.
- 원본 인물 유지
- 불필요한 카메라 효과 금지
- 짧은 자막만 사용

### J02 WORD_CAPTION
1~4단어의 일반 자막.
- 굵은 산세리프
- 흰색 중심
- 얇은 어두운 외곽선/그림자 허용
- 중앙~하단 중앙, 인물의 가슴/배 영역 주변
- 얼굴을 가리지 않는다.

### J03 BIG_KEYWORD
핵심어, 숫자, 강한 동사, 비교 결과.
- 일반 자막 대비 1.7~3배 크기
- 1~3단어
- 화면 중앙 또는 인물 주변 빈 공간
- 대형 타이포 자체가 패턴 인터럽트 역할을 수행
- 한 문장에 여러 번 남용 금지

### J04 NAME_CARD
사람/브랜드/크리에이터 이름 소개.
- 이름을 크게
- 성/핵심 단어 일부에 제한적 포인트 컬러 허용
- 가능하면 해당 인물의 화면/프로필/콘텐츠와 동시에 사용

### J05 TALKING_HEAD_WITH_PROOF
토킹헤드는 유지하고 이미지/스크린샷/영상 자료를 함께 배치.
- 자료는 상단, 배경, 좌우 또는 인물 뒤
- 인물 얼굴과 자료의 핵심 정보를 겹치지 않는다.
- 자료가 작아져 읽을 수 없으면 J06으로 전환

### J06 FULLSCREEN_PROOF
스크린샷, 문서, 포스트, 실제 결과 등 증거가 핵심일 때.
- 토킹헤드 제거 가능
- 0.8~3초
- 문서/스크린샷은 중요한 부분이 읽히도록 크롭

### J07 BROLL_FULL
말의 의미를 직접 보여주는 풀스크린 B-roll.
- 장소, 행동, 제품, 사람, 사건 등에 사용
- 무관한 감성 stock 금지
- 대사와 정확히 연결되는 자산 우선

### J08 BROLL_BURST
2~6개의 짧은 B-roll 연속 배열.
- 각 샷 0.45~1.2초
- 동일 의미의 반복 이미지가 아니라 정보가 전진해야 한다.
- 이야기/사례를 압축할 때 사용

### J09 SOCIAL_GRID / CREATOR_COLLAGE
여러 크리에이터나 사례를 한 번에 비교/소개할 때.
- 2~6개 콘텐츠 캡처/프로필/클립을 격자 또는 빠른 연속 컷으로 제시
- 최종적으로 다시 화자에게 복귀

### J10 CUTOUT_PATTERN_INTERRUPT
인물 배경제거 + 단색/밝은 평면 배경.
- 강한 전환점 또는 결론 직전
- 0.5~1.5초
- 영상 전체에서 최대 1~2회

### J11 MONOCHROME_OR_INVERT_FLASH
흑백, 고대비, 네거티브 등 강한 처리.
- 감정 피크, 실패, 위험, 충격을 강조할 때만
- 0.2~1.2초
- 장식용 반복 금지

## 5. 대사 기능 → 화면 유형 매핑

- 정의/설명 → J01 + J02
- 강한 주장 → J03
- 숫자/금액/거리/기간 → J03, 필요 시 J06
- 특정 인물/브랜드 → J04 + J05/J06
- 실제 사례 → J05/J06/J07
- 여러 사례 나열 → J09 또는 J08
- 장소/여행/행동 → J07
- 시간 순서가 있는 경험담 → J08 중심 MODE 3
- 감정적 실패/고통/위험 → J08 + 제한적 J11
- 핵심 전환 문장 → J10 검토
- 결론/교훈 → J01 또는 J03로 단순화

## 6. 자막 규칙

### 일반 자막
- 한 화면 1~4단어 권장
- 하나의 의미 단위가 끝나면 교체
- 긴 문장 전체를 화면에 고정하지 않는다.
- 굵고 둥근 산세리프 계열의 인상
- 흰색 중심
- 화면의 영상 정보가 복잡하면 가독성을 위한 그림자/외곽선 사용

### 대형 자막
- 숫자, 핵심 명사, 강한 형용사, 결론에만 사용
- 일반 자막 대비 1.7~3배
- 화면 면적을 적극적으로 점유할 수 있음
- 한 화면에 큰 키워드가 여러 개 경쟁하지 않게 한다.

### 배치
우선순위:
1. 인물 얼굴을 피한다.
2. 인물 손동작을 가리지 않는다.
3. 모바일 UI 안전 영역을 피한다.
4. B-roll의 주 피사체를 가리지 않는다.

## 7. B-roll 선정 규칙

### 사용해야 하는 경우
- 특정 장소가 언급됨
- 특정 사람/브랜드/크리에이터가 언급됨
- 실제 경험이나 사건을 이야기함
- 숫자/결과를 증명할 자료가 있음
- 화자의 말만으로 이해하기 어려운 상황
- 같은 토킹헤드 정보구조가 3초 이상 지속됨

### 사용하지 말아야 하는 경우
- 의미와 직접 상관없는 감성 stock
- 단지 화면을 바꾸기 위한 랜덤 영상
- 화자의 핵심 감정 전달을 방해하는 B-roll
- 같은 종류의 클립을 의미 없이 반복

### asset_query 작성법
구체적으로 작성한다.
나쁜 예: `success video`
좋은 예: `young creator filming vertical content in home studio smartphone`.

고유명사나 정확한 증거가 필요한 경우 stock 검색으로 대체하지 말고 `requires_exact_asset=true`로 표시한다.

## 8. 리듬 규칙

- 기본 상태에서 3초 이상 정보 구조가 동일하면 변화가 필요한지 검토한다.
- 변화의 우선순위:
  1. 자막 의미 단위 교체
  2. 핵심어 크기 변화
  3. 자료 오버레이
  4. B-roll
  5. 풀스크린 증거
  6. 강한 패턴 인터럽트
- 의미 없는 줌인/줌아웃 반복으로 리듬을 만들지 않는다.
- 빠른 몽타주가 끝나면 토킹헤드로 복귀한다.
- 하드컷을 기본값으로 한다. 과도한 전환 효과는 사용하지 않는다.

## 9. 레퍼런스에서 측정된 컷 밀도
아래 값은 ffmpeg scene threshold 0.28 기준의 '큰 장면 변화'이며 자막/그래픽 변화는 포함하지 않는다.

- `Da7zY1vgJX2` 48.0초: 감지 컷 14회, 컷 사이 중앙값 약 3.21초
- `DbVP68dgw0d` 43.2초: 감지 컷 25회, 컷 사이 중앙값 약 1.23초
- `DbicmDVAweu` 52.0초: 감지 컷 56회, 컷 사이 중앙값 약 0.79초

이 차이는 '영상마다 스타일이 다르다'가 아니라 이야기의 강도에 따라 편집 밀도를 조절한다는 근거로 사용한다.

## 10. 자동 모드 선택
전체 영상이 아니라 구간 단위로 모드를 선택할 수 있다.

### EXPLAINER score 증가 조건
- 정의, 팁, 규칙, 리스트
- 추상 개념 설명
- 화자의 의견 전달

### HYBRID score 증가 조건
- 사례 이름 등장
- 비교/예시가 여러 개 등장
- 화면으로 보여줄 자료가 존재

### STORY_MONTAGE score 증가 조건
- 과거 시점 표현
- 사건의 순서가 존재
- 여행/도전/실패/감정 변화
- 장소/시간/행동이 연속적으로 등장

전환 예:
`EXPLAINER → HYBRID → STORY_MONTAGE → TALKING_HEAD_RESET`

---

## 11. 금지사항
- 영상 전체를 대형 자막으로 덮기
- 모든 문장을 같은 크기의 자동자막으로 처리
- 1초마다 이유 없이 화면 흔들기/줌하기
- 의미 없는 밈 또는 stock 삽입
- 화자 얼굴을 자막/자료로 지속적으로 가리기
- 강한 흑백/반전 효과를 반복 사용
- B-roll montage를 8초 이상 계속해서 화자를 잊게 만들기
- 레퍼런스 한 편의 일회성 디자인을 전체 영상의 절대 규칙으로 만들기

## 12. 출력 전 자체 검사
렌더 전에 다음 질문에 YES여야 한다.

1. 토킹헤드가 영상의 기준점인가?
2. 일반 자막이 짧은 의미 단위로 끊기는가?
3. 중요한 단어만 크게 보이는가?
4. B-roll마다 대사와 직접적인 의미 연결이 있는가?
5. 사례/증거는 실제 자료로 시각화됐는가?
6. 이야기의 강도가 높아질 때 컷 밀도도 높아지는가?
7. 빠른 몽타주 이후 화자로 복귀하는가?
8. 의미 없는 줌/전환이 제거됐는가?
9. 패턴 인터럽트가 희소하게 사용됐는가?
10. 첫 3초에 최소 한 번 강한 시각적 후킹이 존재하는가?
