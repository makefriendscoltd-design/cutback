# EP07–12 v5 corrections against EP06-v4

The user rejected EP07–12-v4 because its generic panels and camera rhythm differed from the approved EP06-v4. These sources reuse EP06's hook, physical ID badge, native comment field, typography, presenter geometry, continuous drift and motion constants. Episode-specific storyboards show task input, changing state and result; presenter, lower-card and graphic-only beats alternate. Spoken captions, original cuts and private voice/presenter inputs are preserved.

`build.py` is the composition engine; `storyboard.py` contains each episode's timing and graphics. Both are required. Action and camera events drive each episode's freshly generated soundtrack. Example interfaces are labelled as illustrations; they are not live product tests or benchmark results. EP10's review table uses neutral A/B/C results, not invented model performance.

## Reproduce an included episode

From this package, with the existing Python/Node/FFmpeg prerequisites:

```sh
export OWEN_AUDIO_DIR="$PWD/assets/audio"
python3 videos/ep07-v5/build.py
python3 videos/check_owen_camera.py videos/ep07-v5
python3 videos/verify_owen_v5.py videos/ep07-v5
```

Builds use included cuts and transcripts without private media. Mixing/rendering requires the episode's original already-cut `assets/person.mp4` and matching `assets/voice.m4a`, intentionally excluded from Git. Arbitrary replacement footage needs its own source timing, transcript, captions and face coordinates.

```sh
python3 videos/ep07-v5/mix.py
node videos/ep07-v5/qc/caption-audit.mjs
(cd videos/ep07-v5 && npx --yes hyperframes@0.8.107 check --json)
python3 videos/render_owen_v4.py --project videos/ep07-v5 --output renders/episode07-v5.mp4
python3 videos/ep07-v5/qc/verify_render.py videos/ep07-v5/renders/episode07-v5.mp4
```

The wrapper retains its historical filename and accepts v5 project directories. Use HyperFrames 0.8.107. The optional action verifier needs NumPy and the production delivery naming; the delivery inventory verifier needs all six production media and QC trees. Public-only builds are not full render tests. Windows/WSL rendering is unverified.

## Review evidence

Each episode's REPORT.md records production checks and limitations. `videos/owen-v5-delivery.json` binds production MP4s to source, storyboard, events, mix and contact-sheet hashes. Final encoded scene/action/transition samples are reviewed in addition to source and runtime checks. Full-track direct listening has not been performed. User acceptance of v5 is not inferred from automated checks.

The previous v4 scripts and reports remain unchanged historical implementations except for their rejection notice. `V5_SOURCE_MANIFEST.json` lists the copied files and hashes. Private footage, voice, final MP4s, credentials and publishing automation remain excluded. No external posting is performed by this handoff.

All six exported engines were built in the isolated public package and passed camera/reference guards. Production MP4 validation passed for all six at 1080×1920 / 30 fps with zero decode errors and 0 ms mix-alignment lag. EP12 required `qc/remux_final.py` to replace renderer-attenuated audio with its verified own mix; video was stream-copied. Run that step after rendering EP12 if the loudness check detects attenuation.
