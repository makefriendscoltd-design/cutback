EP06-v4 is the approved reference. The EP07–12-v4 outputs below were rejected by the user for format differences. They remain historical records, not accepted examples. See [v5 corrections](V5.md).

Approved on 2026-10-02 from episode6 v4. The episode7 v3 package remains available as historical reference. This revision uses HyperFrames0.8.107.

The editing authority is each episode's `build.py`; it maps source seconds into output time and writes named action events. The mixer consumes those same events. Documentary screenshots move in original image coordinates. Example UI changes state through the narrated task; it is labelled as an example. Clean presenter beats alternate with upper-card and full-graphic scenes. Four font roles distinguish Korean narration, editorial emphasis, code/data and pixel accents.

Direct full-track human listening was not performed.

## Run locally

Use the existing package's macOS/Linux Python, Node and FFmpeg prerequisites. Windows still requires WSL2; v4 has not been tested on a Windows machine. The following example assumes the working directory is this package:

```sh
export OWEN_AUDIO_DIR="$PWD/assets/audio"
python3 videos/ep06-v4/build.py
python3 videos/check_owen_camera.py videos/ep06-v4
```

Before mixing or rendering, supply the exact approved, already-cut silent presenter video at `videos/ep06-v4/assets/person.mp4` and the matching voice at `assets/voice.m4a` in the same episode directory. Private source/presenter media and delivery MP4s are intentionally absent. Included timing and transcript describe the original recording; arbitrary new footage requires its own cuts, transcript, captions, scene cues and face coordinates.

```sh
python3 videos/ep06-v4/mix.py
(cd videos/ep06-v4 && npx --yes hyperframes@0.8.107 browser ensure)
node videos/ep06-v4/qc/caption-audit.mjs
(cd videos/ep06-v4 && npx --yes hyperframes@0.8.107 check --json)
python3 videos/render_owen_v4.py --project videos/ep06-v4 --output renders/episode06-v4.mp4
python3 videos/ep06-v4/qc/verify_render.py videos/ep06-v4/renders/episode06-v4.mp4
```

The new render wrapper uses the same local GPU lock as the historical renderer and disables foreground presentation. Final verification takes an explicit MP4 path. Inspect actual encoded action and transition frames before accepting a new episode; static compilation and numeric checks alone do not establish visual quality. Never reuse the old mixed soundtrack after changing action timing.

`V4_SOURCE_MANIFEST.json` records exported source hashes. Script files are unchanged from their production sources. Report copies replace the local project path with a placeholder. No credentials, publishing automation, private video, session archives or render caches are included. Existing asset licensing terms remain applicable; this update introduces no external publishing permissions.
