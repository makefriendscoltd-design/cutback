# 직원 Codex 인수인계
먼저 START_HERE.md를 읽고 의존성 검사 → 15초 미리보기 → 실제 화면 검사 순서로 진행한다. Windows 실기 검증 전에는 작동 완료라고 말하지 않는다. Claude를 호출하지 않는다.

현재 결과는 바이어 미팅 강의 v2다. 캡컷 네이티브 프로젝트는 없다. Python/FFmpeg 합성이 최종 출력 경로이고 graphics/는 편집 가능한 HyperFrames HTML이다. 원본은 source/original.mp4, 컷 완료 중간 영상은 cut-base.mp4다. 수정은 정본에서 하고 재생성한다. 이전 결과는 보존한다.

자막은 Pretendard SemiBold, 흰색, 검정 블록 68%, ASS 50, 하단 마진132. 한 문장을 한 번에 보여주고 실제 너비1400px를 초과할 때만 의미 단위로 나눈다. 짧은 시간·고정 글자 수로 나누지 않는다. 최대2줄 요청보다 엄격하게 현재 한줄로 구성되어 있다. sentence-groups.json이 문장 정본이고 build_captions.py가 표시 구간을 만든다. 마침표는 표시하지 않는다.

새 영상을 받으면 이 폴더를 복사하여 별도 프로젝트를 만든다. 원본 전사와 대조해 고유명사를 교정하고 새 sentence-groups와 컷 계획을 만든다. 이 강의의 자막·타임코드·슬라이드 크롭·그래픽을 다른 영상에 그대로 사용하지 않는다. 현재 crop은 원본 강의 화면 전용이다. Windows 전사는 MLX 대신 해당 PC에서 사용 가능한 전사 엔진을 선정하고 정확도를 원음으로 확인한다. 새 영상 자동 입력부터 완성까지는 아직 구현된 범용 파이프라인이 아니다.

웍스 인증·계정·비밀번호는 포함되어 있지 않다. 업로드 시 직원 계정으로 접속하고 목적지와 사용자 발송 지시를 확인한다. 제공자 완료 표시와 파일 목록으로 실제 업로드를 검증한다.
