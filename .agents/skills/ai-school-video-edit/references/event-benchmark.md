# 내용에 맞춘 모션그래픽과 타이밍 대조

## 측정 단위

선택한 원본별 편집 이벤트 표를 만든다. 표본 시트와 scene 후보는 탐색 도구이며, 전체 타이밍의 완성 증거가 아니다. 시간은 디코딩 PTS/프레임 인덱스에서 읽고 관찰 시트와 대조한다. 애매한 시작/종료는 범위와 신뢰도를 남긴다.

이벤트마다 기록할 필드:
- reference_id, event_id, event_type, source_start_frame/end_frame, source_start_pts/end_pts, confidence, evidence_frame_paths.
- spoken_word_or_clause_anchor, offset_from_speech_anchor, appearance_duration, hold_duration, exit_duration.
- bbox_xywh_normalized, z_order, person_occlusion, opacity, scale, position/rotation path, observed intermediate states. easing 후보와 실제 관찰값을 분리한다.
- target_clause_anchor, target_start/end, target_asset_id, adaptation_reason. 단순히 원본 초를 다른 길이의 대사에 그대로 붙이지 않는다.

전수 범위는 헤드카피·대사 자막의 교체, 촬영본 컷, B-roll 시작/종료, B-roll 내부 요소의 각각의 움직임, 카운터/막대/커서 변화, 인물 크기·위치·마스크 변화, 장면 전환, 효과음 onset/종료, 음악 진입/퇴장/덕킹이다. 없는 항목은 관찰 범위와 함께 없음, 확인 못 한 항목은 미확정으로 남긴다. 무음 검출·ASR만으로 SFX/음악 타이밍을 확정하지 않는다.

## 헤드카피 전용 대조

1. 커버 한 프레임/짧은 표지, 실제 영상의 도입 헤드카피, 전편 고정 제목을 별개로 식별한다. 큰 표지가 짧게 나왔다면 길게 유지하지 않는다.
2. 새 대사의 주제에 맞게 후킹 문구를 작성한다. 레퍼런스의 문장 길이·행수·강조 구조를 참고하며 학교의 사실은 기존 정본으로 확인한다.
3. 폰트 패밀리와 굵기·실제 글자 높이/너비·자간·행간·줄바꿈·정렬·화면 점유율·좌표·스트로크·그림자·색·회전·인물 앞뒤 겹침을 따로 비교한다. CSS/ASS font-size와 보이는 글자 높이를 혼동하지 않는다.
4. 원본의 서체 식별 근거가 없으면 후보 서체로 같은 문구를 렌더해 원본 크롭과 나란히 비교한다. 가장 가까운 대체라도 원본 서체 확인이라고 부르지 않는다.
5. 등장 직전/등장 중/완전히 표시/퇴장 중/퇴장 직후를 프레임 단위로 대조한다. 축소된 콘택트 시트 한 장만으로 타이포 일치를 선언하지 않는다.

## 모션그래픽 B-roll 제작

화면의 외형으로 AI 제작 여부까지 확정할 필요는 없다. 관찰한 그래픽 문법은 새 내용에 맞게 반드시 구현한다.
- 문장→설명할 대상→그래픽 내부 상태 전개의 순서로 스토리보드를 만든다. 예: 내 기록 정리 설명은 자료 묶음 등장→분류→검색 결과 순서. 새 영상에 관계없는 원본 제품 로고·랭킹·UI를 복사하지 않는다.
- 이미지/질감/배경 등 필요한 애셋은 AI로 만들 수 있다. 한국어·수치·UI 라벨은 편집 가능한 텍스트로 조판해 생성 이미지 속 깨진 글자를 피한다.
- 카드 이동, 연결선, 선택 상태, 수치 증가, 마스크, 레이어 겹침, 그림자/발광 변화가 있으면 각각 seek 가능한 애니메이션 트랙으로 작성한다. hyperframes의 motion-graphics/animation/core 지침을 해당 제작 시 읽는다.
- 도입→정보 추가→강조→정착→퇴장의 각 구간을 원본 이벤트에 연결한다. 장면 전체 재생 시간만 같고 내부 움직임이 다르면 타이밍 재현으로 통과시키지 않는다.
- 원본 모션이 없는 계열에는 장식 모션을 억지로 추가하지 않는다. 실제 사용 화면과 교육 성과는 실제 증거 애셋을 쓰고 설명용 합성을 사실 증거로 위장하지 않는다.

## 렌더 대조와 완료 조건

원본 이벤트 표와 출력 이벤트 표를 연결하고 누락 이벤트·타이밍 차이·레이아웃 차이·서체 대체 여부를 남긴다. 새 대사의 길이가 다르면 문장/강조어를 기준으로 재배치하고 속도·유지 비율의 변경 이유를 설명한다. 임의로 전체 시간축을 늘리거나 평균 컷 간격만 같게 하지 않는다.

실제 렌더의 헤드카피, 대표 B-roll의 내부 움직임, 대사 컷, 자막, 오디오를 나란히 재생/청취해 검수한다. 정량 점수·합격 판정으로 개선할 때는 assay의 근거 봉인/독립 검증 절차를 적용한다. 새로운 테스트나 자체 점수만으로 레퍼런스 재현 완료라고 보고하지 않는다.

이 문서는 요구와 작업 절차다. 현재 6개 원본의 전수 이벤트 표·음원 청취·정확한 폰트 식별이 모두 끝났다는 기록이 아니다. 현재 상태는 styles.json의 analysis_completeness를 따른다.
