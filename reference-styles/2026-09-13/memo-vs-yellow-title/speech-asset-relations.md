# 발화와 부연 애셋의 관계 — 2026-09-13

확인 방식: 다운로드된 두 원본의 음원에 로컬 faster-whisper-small 영어 ASR을 실행하고 같은 시간의 프레임/콘택트시트와 대조했다. 사람이 직접 청취한 검증으로 보고하지 않는다. 자동전사의 cloud code는 화면의 Claude Code와 다르며, 숫자와 고유명사를 검증 없이 복사하지 않는다. 전사는 각 원본 폴더 speech-transcript.json에 보존한다.

- A 16.3–19.44초: IDE 설치와 구체적인 도구 예시를 말한다. 상단 단계 라벨 뒤에 VS Code, Antigravity 아이콘을 보여준다. 부연 역할은 도구 식별이다.
- A 21.36–23.6초: 유료 플랜의 로그인에 관한 발화. Sign In 라벨과 로그인 화면을 보여준다. 부연 역할은 실행할 화면 제시다.
- A 23.8–29.9초: 원하는 사이트에서 우클릭하고 개발자 도구를 여는 행동을 설명한다. 사이트/메뉴 캡처와 빨간 원이 조작 위치를 짚는다. 아래에는 해당 순간의 발화가 따로 표시된다.
- A 30.12–33.48초: body 태그의 메뉴를 복사하는 설명. 전체 캡처와 해당 메뉴 표시가 행동을 시각화한다. 상단 라벨만으로 끝나지 않는다.
- A 33.74–37.78초: 복사한 것을 붙여넣되 아직 전송하지 말라는 설명. 입력 화면과 주의 라벨이 순서대로 등장한다.
- B 7–15.14초: 학습, 저축 계좌, 자동 저축, 비상금에 관한 발화. 번호·노란 제목은 각 항목의 이름을 유지하며 아래 자막은 발화에 맞춰 별도로 바뀐다. A처럼 큰 조작 캡처를 넣는 구성과는 다르다.

제작 적용: 상단은 '요약 제목'으로 한정하지 않는다. 식별이 필요한 말에는 아이콘/대상 이미지, 절차에는 순서 도식, 조건에는 비교/체크 표시, 설명할 화면에는 캡처를 배치한다. 사용자 원본에 없는 실적·실제 작업 화면을 만들어 증거처럼 보이지 않게 한다. 하단은 고정된 꼬리물기 음성 전사다.

V2 대표 프레임 수정 판단: 설명 도식을 머리 위에만 두면 부연 역할은 생겨도 원본 A의 큰 자료 제시 방식은 남지 않는다. 번호·짧은 제목은 상단에 두되 실제 읽을 자료는 중앙까지 넓힌다. 얼굴을 일시 가리는 구간과 인물만 보이는 구간을 교차한다.
