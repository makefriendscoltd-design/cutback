## 카페 정리글 골격 (facts.md §설치 README 원문)
1. 준비물: Node.js 22+, FFmpeg
2. 스킬 설치: `npx skills add heygen-com/hyperframes` (Core Skills 선택) / 비대화형 `npx hyperframes skills update`
3. 첫 영상: `npx hyperframes init my-video` → `preview` → `render`
4. 클로드 코드에 시키는 프롬프트 예시 3개(세로 자막 영상 / 숫자 강조 / 클립 컷)
5. 우리 결과물: 릴스 + 제작 과정 영상 링크
6. 한계: 촬영본 정밀 편집은 프리미어, 클라우드 렌더는 유료
- 이 명령어들은 이 맥에서 실제로 쓰는 명령이라 검증됨(0.8.62~0.8.63).
