## 카페 정리글 골격 (명령어는 facts.md §2 README 원문)
1. 한 줄 요약 + 주의 2개(클로드 무료 아님 / 학습 가능성)
2. 설치: 맥·리눅스 curl 한 줄 / 윈도우 PowerShell 한 줄
3. 키 연결: NVIDIA 키 발급 → Admin UI 붙여넣기 → Apply
4. 실행: `fcc-claude`, 클로드 코드 안에서 `/model`
5. 자동 넘김: Model Config → Fallback Models 순서 추가
6. 로컬 모델: `ollama pull …` → `ollama/<태그>`
7. 삭제 명령
- ⚠️ 설치 스크립트는 실제 실행 검증 전(README 복사본). 게시 전 스크래치 환경에서 설치·`fcc-claude` 실행을 확인하거나, 확인 전이면 "README 기준"이라고 표기.
