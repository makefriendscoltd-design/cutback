## 2편 · 무료 모델로 넘기기 (고칠 게 제일 많음)
- 한도 걸려서 멈추면 대신 일하는 직원이에요 → 한도 걸리면 **두뇌만 무료 모델로 갈아끼우는** 직원이에요
- 무료로 열어놓은 모델을 53곳 모아놓은 건데 → 모델 제공처 **53곳을 붙일 수 있는데**, 구글·엔비디아처럼 무료로 열어둔 곳이 많아요
- 한 모델 한도가 끝나는 순간 다음 모델로 알아서 넘어가요 → **순서만 정해두면** 한 모델 한도가 끝날 때 다음 모델로 알아서 넘어가요
- 맥은 명령어 한 줄이고 → 설치는 명령어 한 줄이고, **키 하나만 붙여넣으면** 돼요
- 무료 모델은 학습에 쓸 수 있으니까 → 무료 모델 중엔 **학습에 쓰는 곳도 있으니까**

## 3편 · 하이퍼프레임즈
- 별이 벌써 4만 개 → **5만 개**
- 그냥 깔면 클로드 코드가 알아서 씁니다 → **깔아두면** 필요할 때 알아서 씁니다
- 그러니까 프리미어 켤 필요가 없어요 → **자막·모션그래픽은** 프리미어 켤 필요가 없어요
- 촬영 영상을 손으로 만지는 편집기는 아니에요 → **프리미어처럼 촬영본을 다듬는** 편집기는 아니에요
- 무료고요 → **내 컴퓨터에서 뽑으면** 무료고요

## 4편 · 디자인 도구 5개

- 자전거 사진 한 장 주면 … 3D를 코드로 → 자전거 **이미지** 한 장 주면 클로드가 **코드로 3D로 다시 만들어요. 마우스로 돌려볼 수 있어요**
