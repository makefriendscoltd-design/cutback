  - 검사 스캔 → 칩이 사라짐(정리) → 어색한 표현에 줄 긋고 새 표현으로 바꿈
  - GitHub 실제 캡처: 전체 → 저장소 제목 확대 + 테두리 → MIT license 탭 확대 + 테두리
  - README 명령 3개를 `\` 줄잇기로 6줄로 나눠 24px로 키움. v1의 19.5px 지적사항 반영
  - 요청문을 발화 구절에 맞춰 입력 → 전송
  - 블로그·상품 타일 → 올리기 전 점검 바 → 체크
  - 원본/수정본 diff: 3곳에 하나씩 줄 긋기 → 바뀐 부분 3곳
